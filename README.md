Project: University Search
This is a university search project that I built while learning how to work with APIs using JavaScript. I used the Fetch API and Axios to make requests and retrieve data.

The project lets users type a state or place name into a search box. Then it shows a list of universities that match the input. The results are pulled from an API.

What I Learned
- Getting data from an API
- Using Axios in JavaScript
- Dealing with API responses
- Showing API data on a webpage in time
- Working with asynchronous code in JavaScript
- Setting up basic error handling

API Used:
The project uses the **University Domains and Names API** which was created and is maintained by Hipo.

GitHub Repository:https://github.com/Hipo/university-domains-list-api
